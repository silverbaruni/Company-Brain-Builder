# Decisioni

Una scheda per ogni decisione da ricordare, creata con `/brain-decisione`.

- Nome file: `AAAA-MM-GG-titolo-breve.md`
- Contenuto: decisione, contesto, perché, alternative scartate, chi ha deciso, quando rivederla.
- Se una decisione viene superata, non cancellarla: aggiungi `Superata da: {file nuovo}`.
