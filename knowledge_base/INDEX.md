# Knowledge base

Tutta la conoscenza dell'azienda. Quando devi rispondere a una domanda, parti da qui.

## Struttura

| Cartella | Cosa contiene | Esempi |
|---|---|---|
| `contesto_installazione/` | Quanto raccolto da `/brain-intervista` e il piano di installazione | `profilo_azienda.md`, `strumenti.md`, `piano_implementazione.md` |
| `chi_siamo/` | Identità dell'azienda: storia, mission, vision, valori, obiettivi | `azienda.md` |
| `team_e_reparti/` | Persone, ruoli, reparti, chi decide cosa, chi sa cosa | `team.md`, `organigramma.md` |
| `pricing/` | Prodotti, servizi, listini, condizioni commerciali | `offerta.md`, `listino_2026.md` |
| `procedure/` | SOP: procedure operative del team, una per file | `onboarding_cliente.md` |
| `brand/` | Design system e brand: loghi, font, colori, tono di voce | `tono_di_voce.md`, `colori.md`, `loghi/` |
| `documenti/` | Tutto il resto: contratti modello, presentazioni, report | |

## Regole

- Un argomento per file, nome in minuscolo con `_`.
- In cima a ogni file: `Aggiornato il: AAAA-MM-GG` e la fonte (es. "intervista", "documento allegato", "Google Drive").
- I file binari (PDF, immagini, loghi) vanno accanto a un `.md` che ne descrive il contenuto.
- Se aggiungi una nuova cartella qui, aggiorna questa tabella e la sezione 3 di `AGENTS.md`.
