# Riferimenti API

Una guida per ogni connettore di tipo `key+ref`: `{tool}-api.md`.

Ogni guida contiene:
- link alla documentazione ufficiale;
- nome della variabile in `.env`;
- come autenticarsi;
- le 3 o 4 chiamate più utili per questa azienda, con esempio;
- limiti (quante richieste, cosa non si può fare).
