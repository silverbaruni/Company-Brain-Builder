# Progetti

Un progetto per ogni lavoro specifico: una nuova skill, un'automazione, un'analisi. Li crea `/brain-evolvi`, ma puoi crearli anche a mano.

## Struttura di un progetto

```
progetti/
└── AAAA-MM-GG-nome-progetto/
    ├── progetto.md     # obiettivo, scheda IDEA, domande e risposte, piano
    └── outputs/        # file prodotti (documenti, artifact, report)
```

Il formato di `progetto.md` è descritto nella skill `brain-evolvi` (cartella delle skill: vedi `AGENTS.md` sezione 3). Quando un progetto è concluso, imposta `Stato: fatto`.
